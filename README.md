## Engineering Philosophy

I care about software that is **fast, maintainable and useful** — not just technically impressive.

- Build simple before building complex.
- Prefer strong foundations over unnecessary abstraction.
- Design for the product, not the framework.
- Automate repetitive work.
- Ship early, learn quickly, iterate continuously.
- Keep the stack modern, but use technology for a reason.
